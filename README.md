# 📁 Smart File Organizer

## 📌 About the Project
Smart File Organizer is a Python-based automation project that organizes files into separate folders according to their file extensions. It makes file management easier by automatically sorting files such as images, documents, videos, music, and Python files.

## ✨ Features
- Automatically organizes files by file type.
- Creates category folders when needed.
- Supports images, documents, videos, music, and Python files.
- Places unrecognized file types in an Other_Files folder.
- Skips files when a file with the same name already exists in the destination folder.
- Simple and beginner-friendly program.

## 🛠️ Technologies Used
- Python
- os module
- shutil module

## 🚀 How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   python organizer.py

6. Enter the path of the folder you want to organize when prompted.

## 📂 Folder Categories
The program sorts files into these folders:
- Images
- Documents
- Videos
- Music
- Python_Files
- Other_Files

## ⚠️ Important Note
This program moves files from their original locations into categorized folders. Test it on a sample folder containing unimportant files before using it on important data.
